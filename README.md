# Reshis Airlines Backend

## Стек
- Язык: Java 17
- Фреймворк: Spring Framework
- Архитектура: MVC
- Хостинг: [Railway](https://railway.com/)
- Ассистент: Claude

## Описание
Бэкенд для турнира "Решись!", направления "Технологии", блока "Разработка". Взаимодействует с [фронтендом](https://github.com/goset33/Airlines-Frontend). Реализованный функционал:
- Парсинг данных о перелетах из CSV таблиц.
- Прогнозирование медианного спроса по данным формулам, а также спроса по квантилям.
- Регистрация и авторизация через Yandex OAuth.

## Подробнее об авторизации
Я очень не хотел поднимать базу данных чтобы хранить сессии и пользователей, а потому придумал схему авторизации, при которой бэкенд вообще не хранит сессии. Верификация пользователя проходит через Yandex ID, а бэкенд получает от Яндекса UserId и на основании него строит JWT токен, который и выдает клиенту.  
Бэкенд выдает Refresh токены и Access токены. Пока у клиента есть действующий Refresh токен, он может пользоваться сервисом. Refresh токен истекает через 14 дней.
